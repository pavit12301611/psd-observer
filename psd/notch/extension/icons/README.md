# Notch chrome icons

Original monochrome SVG drawings for the notch chrome. They are loaded as file
icons so third-party Shell/icon themes cannot replace them with blue/full-color
icons. Notification application icons still use their original full-color
sources. License: GPL-3.0-or-later, same as the project.

Build 19 keeps only the icons used by Home/Music/Alerts/System, the closed music
wings, the sliders settings button and the charging cue. Clipboard, shelf,
volume, pagination, helper and the old sun-like settings icons were removed.
